# Сервисы Smart Meal AI

| ID | Сервис | Ответственность | Ссылка |
|---|---|---|---|
| MS-1 | Gateway | Единая точка входа, маршрутизация, JWT, лимиты запросов, отзыв токенов | [smai-api-gateway](https://github.com/Sun1tAr/smai-api-gateway) |
| MS-2 | Dictionary | Справочники привычек, диет, аллергенов и кухонной техники | [smai-api-dictionary](https://github.com/Sun1tAr/smai-api-dictionary) |
| MS-3 | User | Регистрация, проверка пароля, профиль | [smai-api-user](https://github.com/Sun1tAr/smai-api-user) |
| MS-4 | Recipes | Генерация меню, рецепты, замена блюд, лайки, история, корзина | [smai-api-receipes](https://github.com/Sun1tAr/smai-api-receipes) |
| MS-0 | APK Kiosk | Хранение и выдача Android-сборок, страница версий | [smai-sys-apk-kiosk](https://github.com/Sun1tAr/smai-sys-apk-kiosk) |
| — | Infrastructure | Compose-стеки, сети, деплой и наблюдаемость | [smai-infra](https://github.com/Sun1tAr/smai-infra) |

Названия репозиториев сохранены как технические идентификаторы. В публичном
описании проекта используется полное название Smart Meal AI.
